# 📁 Organizador Automático de Pastas em Python

Um script em Python simples e eficiente que organiza automaticamente os arquivos de qualquer diretório do computador, movendo-os para pastas categorizadas com base em suas extensões.

---

## 🚀 Funcionalidades
- **Categorização Automática:** Identifica os tipos de arquivo (`.jpg`, `.pdf`, `.zip`, etc.) e os move para suas respectivas pastas.
- **Criação Inteligente de Direitórios:** Cria as pastas de destino apenas quando necessário, sem duplicar estruturas.
- **Interativo:** Permite que o usuário informe qualquer caminho do sistema para ser organizado.

---

## 🛠️ Tecnologias Utilizadas
- **Python 3**
- **Módulo `os`:** Manipulação de caminhos e navegação no sistema de arquivos.
- **Módulo `shutil`:** Movimentação e gerenciamento de arquivos.
